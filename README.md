# 📜 Инструкция к проекту Lodge Coffee v2

Этот проект — современный сайт кофейни с динамическим меню и системой заказов, работающий на связке **HTML/JS + Supabase**.

---

## 🚀 Как управлять контентом (Supabase)

Все данные хранятся в облаке. Тебе не нужно менять код, чтобы добавить новый кофе или изменить цену.

### 1. Как добавить новый товар (Меню)
1. Зайди в свой проект на [Supabase](https://supabase.com).
2. Перейди в раздел **Table Editor** (иконка таблицы слева) и выбери таблицу `products`.
3. Нажми **Insert** -> **Insert row**.
4. Заполни поля:
   * **name**: Название (например, `Латте Макиато`).
   * **price**: Только цифры (например, `250`).
   * **category**: Системное имя категории (`coffee`, `tea`, `drinks`, `breakfast` или `desserts`). **Важно:** писать маленькими буквами!
   * **category_name**: Красивое имя для заголовка (например, `Кофе`).
   * **image_url**: Путь к фото (например, `images/latte.jpg`).
5. Нажми **Save**. Товар мгновенно появится на сайте!

### 2. Как проверять заказы
1. В Supabase выбери таблицу `orders`.
2. Здесь ты увидишь:
   * **customer_name**: Имя клиента.
   * **customer_phone**: Номер телефона (в красивом формате).
   * **product_name**: Название выбранного напитка.
   * **status**: По умолчанию стоит `new`. Когда приготовишь заказ, можешь вручную поменять его на `completed`.
